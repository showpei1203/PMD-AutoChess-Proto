PMD AutoChess v1.06.35
VXRD Acceptance Non-Combat Fixture

修正目的：
v1.06.34 的最終驗收使用 H12 作為水域／特殊房／Save-Load／Retreat Fixture，
但玩家現有隊伍戰力不應成為結構驗收條件。

v1.06.35：
- H12 仍保留作正式 production random-floor fixture。
- 只有「VXRD最終驗收」進入的 H12，所有 Encounter 戰鬥均停用。
- 不要求打贏任何 H12 戰鬥。
- 不要求完成 H12 Full Clear。
- 不修改正式 H12 的敵方強度、AI、傷害或掉落。
- Save -> Load 真實序列化驗收保留。
- Retreat semantics 驗收保留。
- H21 Legendary Circuit Gate 驗收保留。

使用方式：
1. 覆蓋 Data/Scripts.rvdata 後重新啟動遊戲。
2. Menu -> VXRD最終驗收。
3. 進入 H12 NON-COMBAT Fixture 後，不需戰鬥。
4. Menu -> Save，然後立刻 Load 同一檔案。
5. 系統自動比對並完成 Retreat + H21 Gate。
6. 顯示 VXRD Windows Integrated Acceptance｜PASS 即完成。

PASS 不需回傳 LOG；FAIL 才需回傳 PMD_VXRD_WindowsAcceptance_LATEST.log。
